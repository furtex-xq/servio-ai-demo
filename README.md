# Servio AI — демо в браузере

**Открыть:** https://furtex-xq.github.io/servio-ai-demo/

Браузерная копия Android-приложения Servio AI: все экраны, шесть ролей на одних данных.

| Роль | Что внутри |
|---|---|
| Старт | Заставка, онбординг, приветствие, активация устройства по коду, вход, регистрация, код подтверждения, создание ресторана, тарифы, оплата, сброс пароля |
| Гость | Вход за столиком, главная, меню, карточка блюда, корзина с промокодами, оформление, история заказов, ассистент, уведомления, «Ещё», информация о ресторане |
| Официант | Панель, столы, стол, заказы, вызовы, «Ещё» |
| Кухня | Кухонный экран: станции, фильтры, таймеры, опаздывающие заказы |
| Владелец | Панель, устройства, лицензии, принтеры, заказы, команда, «Ещё», меню, блюдо, аналитика, столы, редактор плана зала, брони, акции, отзывы, профиль, настройки, безопасность, подписка, оплата, график, клиенты, режим владельца |
| Админ | Super Admin, Big Owner, локализация, диагностика подписки |

Что взято из приложения, а не придумано для демо:

- **Тексты на 9 языках** — из `core/locale` приложения (2170 строк на язык).
- **Ассистент** — офлайн-движок `GetAiResponseUseCase.kt`, перенесён без изменений.
- **Формулы** сводки и аналитики — как в `OwnerDashboardViewModel` (неделя, сегодня против вчера, топ по порциям).
- **Пороги** опоздания на кухне — 5 и 20 минут, как в `KdsState.kt`.
- **Тарифы** — из `SubscriptionPlan.kt`.
- **Демо-ресторан «Golden Bite»** — то же меню, цены, время готовки и калории, что в тестовых данных приложения.

Прямая ссылка на экран: `#роль/экран`, например `#owner/o_analytics`, язык — `?lang=en`.

Ничего никуда не отправляется: нет сервера, оплаты и настоящих аккаунтов. После перезагрузки страницы данные возвращаются к исходным.
