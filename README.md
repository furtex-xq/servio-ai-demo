# Servio AI — демо

Рабочее демо ресторанной системы Servio AI для браузера: три роли на одних данных.

- **Гость** — меню с фотографиями, поиск, корзина, заказ, AI-ассистент, вызов официанта.
- **Официант** — все заказы зала, смена статусов, вызовы со столов.
- **Владелец** — выручка, чеки, средний чек, график по дням, что чаще берут.

Закажите как гость — заказ появится у официанта, а выручка пересчитается у владельца.

Это демо для браузера, а не само приложение: Servio AI — Android-приложение на Kotlin,
здесь воспроизведены его экраны и логика заказа, чтобы можно было попробовать без установки.
Ресторан на экранах демонстрационный.
